# Kotlin Functional Programming Lab

A personal learning repository focused on Kotlin and Functional Programming concepts.

## Overview

This repository contains a collection of independent examples, exercises, and experiments designed to explore Kotlin language features and functional programming principles.

The code is organized as standalone files that can be executed independently. Each file focuses on a specific concept, pattern, language feature, or exercise.

## Objectives

* Learn Kotlin fundamentals
* Explore functional programming concepts
* Practice immutable data structures
* Understand higher-order functions
* Experiment with collections and transformations
* Learn error handling techniques
* Explore concurrency and coroutines
* Build small examples to reinforce learning

## Repository Structure

Each source file is self-contained and can be executed independently.

Examples may cover topics such as:

* Variables and data types
* Functions and lambdas
* Higher-order functions
* Collections API
* Extension functions
* Data classes
* Sealed classes
* Functional error handling
* Coroutines
* Generics
* Design patterns
* Functional programming techniques

## Running the Examples

Open the project in IntelliJ IDEA or your preferred Kotlin environment and execute any file individually to explore the corresponding concept.

This repository is intended for educational purposes only. It serves as a knowledge base, experimentation space, and reference for Kotlin and Functional Programming concepts.
